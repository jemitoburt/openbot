
### Added

- Install Dashboards from the desktop Marketplace Plugins tab and open it from the left sidebar, on local or supported remote hosts.
- Ask agents to create dashboards with checklists, tables, charts, schedules, detail cards, and reports from existing routines. Morning reports stay in the conversation and also appear in a dashboard.
- Open dashboard widgets in a detail view, add recipe ingredients to shopping lists, and send requests from the dashboard Ask bar. The widget kit also includes news, weather, project status, progress, statistics, and action cards.
- Ask an agent to find and restore its archived dashboards with their saved content and checklist state.
